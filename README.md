# sihyeonjeon.github.io

Astro 기반 GitHub Pages 포트폴리오와 기술 블로그입니다.

## Commands

```bash
npm run dev
npm run build
npm run preview
```

## Content

- Blog posts: `src/content/blog/*.mdx`
- Projects: `src/content/projects/*.mdx`
- Post/project images: `src/assets/img/`

디자인 산출물은 `plan.md`의 Claude Design 프롬프트를 기준으로 `src/styles/global.css`, 페이지 hero, SVG assets에 반영합니다.
