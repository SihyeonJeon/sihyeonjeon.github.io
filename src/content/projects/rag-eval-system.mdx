## Why this exists

RAG regressions often appear after prompt edits, model swaps, index rebuilds, or chunking changes. The project target is a system where those changes are measured before merge.

## Planned proof

- golden-set retrieval recall and faithfulness suites
- per-run latency and cost budget
- score records keyed by commit and dataset hash
- GitHub Actions gate that compares a pull request to a baseline branch

## Acceptance bar

This page becomes measured only after a public repo, reproducible benchmark, and at least one visible evaluation run exist.
