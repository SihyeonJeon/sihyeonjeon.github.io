Agent가 쓰는 tool catalog는 무료가 아닙니다.
도구 설명, 파라미터 schema, 예시가 길어질수록 모델은 매번 더 많은 context를 읽습니다.

`tool-tax`의 출발점은 단순합니다.
도구 schema도 latency, memory, bundle size처럼 예산으로 봐야 합니다.

## 좋은 도구 설명의 조건

- 필요한 순간에만 상세 schema를 읽을 수 있어야 한다.
- PR에서 schema 비용 증가를 비교할 수 있어야 한다.
- 서버별 비용 차이를 숫자로 볼 수 있어야 한다.
- 줄인 token이 실제 작업 성공률을 해치지 않는지 확인해야 한다.

이 관점은 agent repo의 문서와 tool definition을 더 작고 선명하게 만듭니다.
