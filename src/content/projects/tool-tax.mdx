`tool-tax` turns invisible tool-schema cost into a number that can be reviewed in CI

## Record

| Field | Detail |
| --- | --- |
| Problem | Tool catalogs enter agent context as hidden fixed cost |
| Obstacle | MCP, OpenAPI, and custom tool manifests have different shapes |
| Fix | Normalize tool schema cost, expose reports, support PR diff review |
| Result | Naive MCP host catalog estimate: 4,091 → 330 tokens through proxy index |
| Guardrail | Local estimates only, not provider billing |

## Built

- CLI for MCP configs, OpenAPI files, and agent tool catalogs
- schema budget reports and PR diffs
- progressive-loading index generation
- lazy-schema MCP stdio proxy experiment
- PyPI distribution path

## Signals

- example report: 1,144 full-tax tokens → 309 slim-index tokens
- filesystem MCP doctor: 2,102 tax tokens → 647 index tokens
- estimated doctor savings: 69.22%
