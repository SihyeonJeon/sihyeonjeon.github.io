## Why this exists

AI infrastructure needs a real client. A workspace makes retrieval quality, prompt behavior, and evaluation output visible in one place instead of scattered across notebooks and logs.

## Planned proof

- streaming comparison UI
- retrieval diff panel
- eval-run history tied to corpus snapshots
- screen capture and local setup path

## Acceptance bar

The project remains planned until the workspace can inspect one corpus, run one eval suite, and replay one model comparison end to end.
