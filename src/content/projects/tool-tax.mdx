`tool-tax` turns invisible tool-schema cost into a number that can be reviewed in CI.

## Built Surface

- CLI for MCP configs, OpenAPI files, and agent tool catalogs
- schema budget reports and PR diffs
- progressive-loading index generation
- lazy-schema MCP stdio proxy experiment
- PyPI distribution path

## Why It Matters

Agent systems often pay for large tool descriptions before a tool is needed.
This project treats tool schema as an engineering budget, not background noise.
