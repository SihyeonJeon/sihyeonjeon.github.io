`site2voice` separates web structure and copy rhythm from source-site subject matter.

## Built Surface

- reusable `SITE.md` and `VOICE.md` context files
- concise CLI/package shape
- source-site contamination guardrails
- examples designed for direct agent injection

## Why It Matters

Good web generation needs structure and tone, but should not inherit the reference site's product nouns.
The project frames those concerns as separate files an agent can read before building.
