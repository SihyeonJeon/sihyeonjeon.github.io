## Why this exists

AI systems need a reliable data and deployment layer around the model. This project will make dataset identity, score provenance, and operational health visible.

## Planned proof

- data contract checks
- drift report with threshold policy
- deployment health dashboard
- rollback and incident runbook

## Acceptance bar

The layer is considered real only when it guards at least one portfolio AI system and exposes the failure mode it catches.
